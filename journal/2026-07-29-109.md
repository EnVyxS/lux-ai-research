## 5. Anatomi BNXUSDT 2022-04 — satu-satunya tersangka, dan ia berbicara

Meski ramalan saya gugur, isinya justru **memperkuat** temuan jurnal 108 §5.3 dan
memberi angka yang belum pernah saya pegang:

| medan | nilai |
|---|---|
| `cacah_baris_1m` | 41.550 |
| `menit_kalender` | 43.200 |
| `menit_hilang_di_tengah` | **1.440** |
| `tepi_awal` / `tepi_akhir` | **210** / 0 |
| `jumlah_terpertanggungjawabkan` | 43.200 |
| `gerbang_lolos` | **false** |
| `gerbang_pelanggaran` | `tanpa_menit_hilang`, `jarak_60_detik` |
| `posisi` | pertama (dikecualikan dari putusan) |
| `putusan` | TEPI_TAK_TERJELASKAN |
| `checksum_bulanan` | `14bd6937…` |

Hitung ulang (aturan 21): 43.200 − 41.550 = 1.650 = 1.440 + 210. Konsisten.

1. **Tepi awal 210 menit itu SAH, bukan kerusakan.** `stempel_pertama_ms`
   1648783800000 = 2022-04-01T03:30:00Z, dan berkas HARIAN 2022-04-01 memang hanya
   memuat 1.230 baris = 1.440 − 210. Kedua tingkat arsip sepakat: BNXUSDT baru
   mulai terbit pukul 03:30 UTC pada hari pertamanya. `menit_tepi_hadir` 0 dari 210
   yang dicari, di bulanan maupun harian.
2. **Maka 1.440 menit yang hilang di TENGAH adalah satu hari penuh yang
   benar-benar tidak diterbitkan** — bukan efek tepi, bukan pemotongan awal.
   Tanggalnya belum diketahui: laporan mencacah menitnya, tidak menyebut harinya.
3. **Bulan itu gagal gerbang, padahal berkasnya ada dan checksum-nya terhitung.**
   Ini persis pembedaan yang dicabut-perbaiki di jurnal 108: `bulan_didaftar`
   (arsip menerbitkan) ≠ bulan lolos gerbang kehidupan. Sekarang pembedaan itu
   punya satu contoh terukur dengan angka.
4. **Penggugur ADR-A004 tidak menyala**:
   `cacah_gerbang_lolos_padahal_tepi_terpotong` = 0, `cacah_tepi_terpotong` = 0,
   `cacah_selisih_tak_terjelaskan` = 0, `cacah_tepi_bersih` 37 dari 38. Keenam
   klausa masih cukup untuk sampel ini.
